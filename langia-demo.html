Kết nối AI model

API key chỉ được lưu trong localStorage của trình duyệt bạn — không gửi đi đâu khác ngoài thẳng tới nhà cung cấp bạn chọn. Lưu ý: một số API (OpenAI, Anthropic) có thể chặn gọi trực tiếp từ trình duyệt (CORS) — nếu gặp lỗi, cân nhắc dùng model/endpoint hỗ trợ gọi từ browser, hoặc proxy qua backend nhẹ.

Khi model chính bị giới hạn lượt gọi (rate limit / hết quota RPD), hệ thống sẽ tự động thử lần lượt các model dự phòng bên dưới, theo đúng thứ tự. Danh sách gợi ý đã kiểm tra qua tìm kiếm web (8/2026) khớp với ID thật trên ai.google.dev — nhưng Google đổi/khai tử model liên tục nên vẫn nên xác nhận lại trên Google AI Studio trước khi phụ thuộc vào chúng.

Về nhóm TTS / Live / Native Audio Dialog bạn hỏi: đã tìm thấy ID thật là gemini-3.1-flash-tts-preview, gemini-2.5-flash-preview-tts, gemini-3.1-flash-live-preview, gemini-live-2.5-flash-preview-native-audio-09-2025 — nhưng đây là API khác hoàn toàn (Live API dùng WebSocket streaming, TTS dùng response modality audio riêng), không tương thích với kiểu gọi generateContent văn bản mà app này đang dùng. Vì vậy chưa thể thêm chúng vào danh sách dự phòng ở đây — Listening/Speaking trong app vẫn dùng Web Speech API miễn phí của trình duyệt.

Model riêng cho từng kỹ năng (tuỳ chọn) — để trống sẽ dùng model chính ở trên. Ví dụ: dùng model nhẹ/nhanh hơn cho Listening/Speaking (chỉ tạo kịch bản văn bản ngắn, giọng đọc/mic vẫn dùng Web Speech API của trình duyệt, không qua model AI), và model mạnh hơn cho Writing (cần chấm điểm bài luận).
